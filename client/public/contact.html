Bugs and contributions

The fastest route for anything about the code is the repository: github.com/sambhavsaxena/tick. Open an issue for a bug, or a pull request if you have already fixed it. Balance arguments are welcome; bring numbers.

What to include in a bug report

  • your browser and operating system;
  • the map, mode and weather from the spawn card, if you saw it;
  • what you expected and what happened instead;
  • anything in the browser console, if you can get at it.
